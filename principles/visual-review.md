# 网页视觉检查清单

用于设计前自查和改版后复盘。每次挑与页面任务相关的项目检查，不机械地追求全部勾选。

## 第一眼

- [ ] 第一眼有明确的重点，标题、图像和按钮不会同时争抢注意力。
- [ ] 标题与画面能帮助访客理解用途。
- [ ] 主要入口容易找到，装饰不会挡住操作。

## 排版与节奏

- [ ] 标题、正文、辅助标注有清晰的尺度差。
- [ ] 中文断行自然，长段文字不会挤成一堵墙。
- [ ] 空白有组织作用，内容不会被等大的卡片平均切碎。
- [ ] 密集的信息留在需要比较和操作的区域。

## 颜色与图像

- [ ] 强调色有明确用途，状态和按钮保持一致。
- [ ] 主视觉与业务有关，能解释为什么选择这张图。
- [ ] 颗粒、阴影、渐变和动效都服务画面，去掉无意义的装饰。
- [ ] 素材保留出处，项目使用范围和授权清楚。

## 实际使用

- [ ] 桌面与手机均看过实际页面，图片裁切和文字断行合理。
- [ ] 正文易读，操作状态清楚，键盘焦点可见。
- [ ] 有动效时尊重减少动态效果的偏好。
- [ ] 原有主要任务实际走通。
- [ ] 留下截图与具体反馈，再决定是否采纳改版。
