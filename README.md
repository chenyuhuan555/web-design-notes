# 网页设计学习笔记

看见一个好看的页面之后，试着说清楚：它为什么好看，哪些做法适合自己的产品，做出来之后是否真的更好。

从 AI、HR 和猎头工具的实际项目出发，记录视觉参考、设计判断与改版复盘。

## 怎么积累

每次围绕一个具体问题：选参考 → 拆解画面 → 提出设计假设 → 在项目中试做 → 看实际页面 → 记录取舍。

参考拆解可以单独成立；实施效果需要前后截图和实际使用检查。尚未实施的想法标记为“待验证”，不把配色方案写成改版成果。

下一步：为寻访研究台试做一个首页视觉方向，先验证标题、主视觉和内容节奏，再决定是否扩展到操作区域。
